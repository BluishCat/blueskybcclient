# Poisora

Blueskyのデスクトップ向けクライアントアプリケーションです（v0.3.0 までの名前は「Bluesky BC Client」）。
パソコンの広い画面を活かして、タイムラインや画像を快適に閲覧・投稿することができます。

## はじめに：ログインについて

アプリケーション（`Poisora.exe`）を起動すると、ログイン画面が表示されます。
*   **Blueskyハンドルネーム:** あなたのハンドルネーム（例: `user.bsky.social`）を入力します。
*   **パスワード:** セキュリティ上、本体のパスワードを直接入力するのではなく、Bluesky公式ウェブサイトの「設定」＞「高度な設定」＞「アプリパスワード」から本アプリ専用のパスワードを発行し、それを使用することを強く推奨します。

※パスワードは Windows の資格情報マネージャーに保存され、次回からは自動的にログインします。`config.json` にはハンドルネームだけが保存されます。

## 画面の見方

本アプリは、情報の見やすさを重視した複数のエリア（ペイン）から構成されています。
各エリアの境界（境目）はマウスでドラッグして好きな大きさに調整できます。

*   **メインメニュー（上部）:** ポストの新規作成や、設定画面を開くことができます。また「フィード」メニューから、特定のタブを隠したり表示したりできます。
*   **タイムライン（中央）:** 指定したタブ（ホーム・通知・ブックマーク等）のポスト一覧が並びます。まだ読んでいない新しいポストは**太字**で強調表示されます。
*   **詳細プレビュー（左下）:** タイムラインで選択したポストの本文、アイコン、リプライ先などを詳細に表示します。URLをクリックするとブラウザで開きます。
*   **画像プレビュー（右下）:** ポストに画像が添付されている場合に表示されます。マウスのスクロール（ホイール）で画像を次々と切り替えることができます。
    動画が添付されたポストではサムネイル（静止画）が表示されます。ダブルクリックすると、その動画を再生できるウェブページがブラウザで開きます。

## 便利な使い方・ショートカット

*   **未読ポストのサクサク消化:** キーボードの **スペースキー** を押すと、タイムラインにある「一番古い未読のポスト」へ自動的にスクロールし、詳細を表示します。連打するだけで新着ポストを順番に読んでいくことができます。
*   **アクションメニュー:** タイムラインのポストや詳細プレビューエリアを **右クリック** すると、そのポストに対する「リポスト」「お気に入り（いいね）」「ブックマーク」や、「プロフィールを表示」などのメニューが開きます。
*   **ブラウザで開く:** ポストを **ダブルクリック** すると、そのポストの Bluesky 公式ウェブページがお使いのブラウザで開きます。
*   **新着サウンド通知:** タイムライン下部にあるタブ（例:「ホーム」と書かれた部分）を **右クリック** すると、新着ポストを受信した際に鳴らす「通知音」を設定できます。

> **※通知音の追加方法**
> アプリと同じ場所にある `sound` というフォルダに、お好みの音声ファイル（`.wav` や `.mp3`）を入れてからアプリを起動すると、タブの右クリックメニューでその音声を選べるようになります。

## ポストを投稿する

画面下部の入力欄（インラインポストエリア）や、メニューの「ファイル」＞「新規ポスト」から新しいポストを投稿できます。

*   **文字数のチェック:** 最大300文字まで投稿可能です。入力文字数は右下に表示されます。
*   **画像の添付:**
    *   **「📁」ボタン** からパソコン内の画像を選んで添付できます。
    *   **ドラッグ＆ドロップ:** 画像ファイルを入力欄やウィンドウに直接ドラッグ＆ドロップして追加できます。
    *   **クリップボードから貼り付け（Ctrl+V）:** ブラウザやペイントソフトでコピーした画像（またはコピーした画像ファイル）を、入力欄を選択した状態で `Ctrl+V` を押すことで直接貼り付けることができます。
*   画像は最大4枚まで添付可能です。添付された画像を右クリック（または×ボタン）で削除できます。
*   プレビューエリアに表示されている小さい入力欄（代替テキスト）に文字を入れると、画像に対してALT（説明文）を設定できます。
*   **動画の添付:** `.mp4` ファイルを「📁」ボタンまたはドラッグ＆ドロップで添付できます。動画は1本のみで、画像とは同時に添付できません（どちらかを添付すると、もう一方は外れます）。
    *   動画は **最大300MB・10分** までです。これを超えるファイルは添付時に弾かれます。
    *   添付するとエンコードの進行状況（「エンコード中 45%」など）が表示されます。ポストが作られるのは処理が終わったあとなので、テキストだけの投稿より時間がかかります。
    *   動画にも代替テキスト（ALT）を設定できます。
    *   ※Bluesky 側の制限により、動画を投稿するにはアカウントのメールアドレス認証が必要です。1日に投稿できる本数にも上限があります。
*   入力欄で `Ctrl + Enter` を押すと、そのままポストを送信できます。

## アンインストール

本アプリケーションはレジストリ等を使用していません。
不要になった場合は、先にメニューの「アカウント」＞「アカウント切り替え」を選んで資格情報マネージャーに保存したパスワードを削除し、ログイン画面を閉じてからアプリのフォルダ（`Poisora.exe` や `config.json` 等が含まれているフォルダ）ごと削除してください。
「アカウント切り替え」をせずにフォルダを削除した場合は、「コントロール パネル」＞「資格情報マネージャー」＞「Windows 資格情報」の「汎用資格情報」から `Poisora` を削除してください（v0.3.0 以前の名前の `BlueskyBCClient` が残っている場合はそちらも）。

## macOS / Linux で使う（非公式・動作未確認）

配布している `Poisora.exe` は Windows 専用です。macOS / Linux 向けの実行ファイルは配布していませんが、ソースコードは他の OS でも動くように書いてあります。ただし作者は Windows 以外で動作確認をしていないため、サポート対象外です。

ソースから起動する場合（Python 3.10 以降、Tkinter 付き）:

```sh
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python bluesky_client.py
```

同じ環境で `pyinstaller Poisora.spec` を実行すると、その OS 用の実行ファイルを作れる可能性があります（未確認）。

Windows 版との違い:

*   **パスワードの保存先:** macOS はキーチェーン、Linux は Secret Service（GNOME Keyring / KWallet など）に保存されます。
*   **ショートカット:** macOS では `Ctrl` の代わりに `Cmd` も使えます（`Cmd+V`、`Cmd+Enter`）。右クリックできない環境では `Control+クリック` を使ってください。
*   **画像の貼り付け（Linux）:** クリップボードから画像を貼り付けるには `xclip`（X11）または `wl-clipboard`（Wayland）が必要です。
