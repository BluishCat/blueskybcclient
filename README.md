# Bluesky BC Client (TweenBS)

Blueskyのデスクトップ向けクライアントアプリケーションです。
パソコンの広い画面を活かして、タイムラインや画像を快適に閲覧・投稿することができます。

## はじめに：ログインについて

アプリケーション（`BlueskyBCClient.exe`）を起動すると、ログイン画面が表示されます。
*   **Blueskyハンドルネーム:** あなたのハンドルネーム（例: `user.bsky.social`）を入力します。
*   **パスワード:** セキュリティ上、本体のパスワードを直接入力するのではなく、Bluesky公式ウェブサイトの「設定」＞「高度な設定」＞「アプリパスワード」から本アプリ専用のパスワードを発行し、それを使用することを強く推奨します。

※ログイン情報はローカルPC内に暗号化されて保存され、次回からは自動的にログインします。

## 画面の見方

本アプリは、情報の見やすさを重視した複数のエリア（ペイン）から構成されています。
各エリアの境界（境目）はマウスでドラッグして好きな大きさに調整できます。

*   **メインメニュー（上部）:** ポストの新規作成や、設定画面を開くことができます。また「フィード」メニューから、特定のタブを隠したり表示したりできます。
*   **タイムライン（中央）:** 指定したタブ（ホーム・通知・ブックマーク等）のポスト一覧が並びます。まだ読んでいない新しいポストは**太字**で強調表示されます。
*   **詳細プレビュー（左下）:** タイムラインで選択したポストの本文、アイコン、リプライ先などを詳細に表示します。URLをクリックするとブラウザで開きます。
*   **画像プレビュー（右下）:** ポストに画像が添付されている場合に表示されます。マウスのスクロール（ホイール）で画像を次々と切り替えることができます。

## 便利な使い方・ショートカット

*   **未読ポストのサクサク消化:** キーボードの **スペースキー** を押すと、タイムラインにある「一番古い未読のポスト」へ自動的にスクロールし、詳細を表示します。連打するだけで新着ポストを順番に読んでいくことができます。
*   **アクションメニュー:** タイムラインのポストや詳細プレビューエリアを **右クリック** すると、そのポストに対する「リポスト」「お気に入り（いいね）」「ブックマーク」や、「プロフィールを表示」などのメニューが開きます。
*   **ブラウザで開く:** ポストを **ダブルクリック** すると、そのポストの Bluesky 公式ウェブページがお使いのブラウザで開きます。
*   **新着サウンド通知:** タイムライン下部にあるタブ（例:「ホーム」と書かれた部分）を **右クリック** すると、新着ポストを受信した際に鳴らす「通知音」を設定できます。

> **※通知音の追加方法**
> アプリと同じ場所にある `sound` というフォルダに、お好みの音声ファイル（`.wav` や `.mp3`）を入れてからアプリを起動すると、タブの右クリックメニューでその音声を選べるようになります。

## ポストを投稿する

画面下部の入力欄（インラインポストエリア）や、メニューの「ファイル」＞「新規ポスト」から新しいポストを投稿できます。

*   **文字数のチェック:** 最大300文字まで投稿可能です。入力文字数は右下に表示されます。
*   **画像の添付:**
    *   **「📁」ボタン** からパソコン内の画像を選んで添付できます。
    *   **ドラッグ＆ドロップ:** 画像ファイルを入力欄やウィンドウに直接ドラッグ＆ドロップして追加できます。
    *   **クリップボードから貼り付け（Ctrl+V）:** ブラウザやペイントソフトでコピーした画像（またはコピーした画像ファイル）を、入力欄を選択した状態で `Ctrl+V` を押すことで直接貼り付けることができます。
*   画像は最大4枚まで添付可能です。添付された画像を右クリック（または×ボタン）で削除できます。
*   プレビューエリアに表示されている小さい入力欄（代替テキスト）に文字を入れると、画像に対してALT（説明文）を設定できます。
*   入力欄で `Ctrl + Enter` を押すと、そのままポストを送信できます。

## アンインストール

本アプリケーションはレジストリ等を使用していません。
不要になった場合は、アプリのフォルダ（`BlueskyBCClient.exe` や `config.json` 等が含まれているフォルダ）ごと削除するだけで完全にアンインストールされます。
